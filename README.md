# FnB-Management-System

**FnB Management System** adalah sistem digital yang digunakan untuk membantu pengelolaan operasional bisnis **Food & Beverage (FnB)** secara lebih efisien. Sistem ini menyediakan fitur untuk mengelola reservasi, pemesanan, pembayaran, katalog produk, serta data pesanan dan reservasi dalam satu platform.

---

# Fitur Utama

## Pemesanan Tempat Duduk (Reservasi)
- Melakukan reservasi meja.
- Mengelola data reservasi pelanggan.
- Melihat status reservasi.

## Pemesanan Makanan & Minuman
- Memesan makanan dan minuman.
- Menambahkan beberapa menu dalam satu pesanan.
- Menghitung total pembayaran secara otomatis.

## Metode Pembayaran
- Mendukung pembayaran melalui **Transfer Bank**.
- Menyimpan informasi pembayaran pada setiap transaksi.

## Katalog Produk
- Menampilkan daftar makanan dan minuman.
- Mengelola data produk (tambah, ubah, hapus).

## Mengelola Data Pesanan dan Reservasi
- Mengelola data pesanan pelanggan.
- Mengelola data reservasi.
- Memantau status pesanan dan reservasi.
